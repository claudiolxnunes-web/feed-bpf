⚡ Configuração — Supabase (gratuito)
Por que Supabase? Banco PostgreSQL gratuito, acessível de qualquer computador, sem servidor próprio. Seus rótulos ficam na nuvem e você acessa de qualquer lugar.
📋 Passo a passo — 5 minutos
1
Acesse supabase.com → clique em Start for free → crie uma conta (pode usar o Google)
2
Clique em New Project → dê um nome (ex: rotulos-hgm) → escolha a região South America (São Paulo) → crie uma senha forte → Create new project
3
No projeto, vá em Project Settings → API e copie:
— Project URL (ex: https://xyzxyz.supabase.co)
— anon public key (começa com eyJ...)
4
Vá em SQL Editor e execute este script para criar as tabelas:
-- Tabela de empresas CREATE TABLE IF NOT EXISTS empresas ( id uuid DEFAULT gen_random_uuid() PRIMARY KEY, nome text NOT NULL, dados jsonb NOT NULL, criado_em timestamptz DEFAULT now(), atualizado_em timestamptz DEFAULT now() ); -- Tabela de rótulos CREATE TABLE IF NOT EXISTS rotulos ( id uuid DEFAULT gen_random_uuid() PRIMARY KEY, nome text NOT NULL, empresa_id uuid REFERENCES empresas(id), produto text, tipo_num integer, dados jsonb NOT NULL, criado_em timestamptz DEFAULT now(), atualizado_em timestamptz DEFAULT now() ); -- Habilitar acesso público (RLS off para uso simples) ALTER TABLE empresas ENABLE ROW LEVEL SECURITY; ALTER TABLE rotulos ENABLE ROW LEVEL SECURITY; CREATE POLICY "acesso_total_empresas" ON empresas FOR ALL USING (true) WITH CHECK (true); CREATE POLICY "acesso_total_rotulos" ON rotulos FOR ALL USING (true) WITH CHECK (true);
5
Cole a URL e a chave abaixo e clique em Conectar
